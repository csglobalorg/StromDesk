## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development
Start the local development server:
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### Production Build
Compile and optimize for production:
```bash
npm run build
```
The output will be in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
